## 2. Описание проекта

**TaskBoard** — веб-приложение для управления задачами с полноценной backend- и frontend-частью.  
Стек: `ASP.NET Core Web API`, `Entity Framework Core`, `SQLite`, `HTML5`, `CSS3`, `JavaScript (Fetch API)`.

### Возможности

- Просмотр списка задач (сортировка: сначала невыполненные, затем по дате создания)
- Добавление задачи (название + описание)
- Отметка о выполнении (визуальное перечёркивание)
- Редактирование названия и описания
- Удаление с подтверждением
- Фильтрация: «Все», «В работе», «Выполненные»
- Счётчик выполненных задач
- Асинхронное взаимодействие с сервером

## 3. Инструкция по запуску

### 3.1. Бэкенд (API)

1. Открыть терминал и перейти в папку `TaskBoardApi`.
2. Выполнить команду `dotnet run`.
3. API будет доступно по адресу `http://localhost:5000`, Swagger — `http://localhost:5000/swagger`.

### 3.2. Фронтенд

1. Убедиться, что бэкенд запущен.
2. Открыть файл `frontend/index.html` через **Live Server** в VS Code (или другим локальным сервером).
3. Проверить в `frontend/js/api.js` переменную `API_URL = "http://localhost:5000/api/tasks"` — порт должен совпадать с бэкендом.

### 3.3. Примечания

- Бэкенд и фронтенд работают одновременно.
- При смене порта изменить его в `Properties/launchSettings.json` и в `api.js`.

## 4. Главные выводы

1. **Полный цикл Fullstack** — научился строить приложение от модели (`TaskItem`) до интерфейса, связывая через REST API.

2. **Асинхронность** — `async/await` на бэкенде (`FindAsync`, `SaveChangesAsync`) и на фронтенде (`fetch`) не блокирует потоки, приложение остаётся отзывчивым.

3. **Модульность** — вынос сетевых вызовов в отдельный `api.js` упрощает поддержку и тестирование.

4. **Управление состоянием на клиенте** — локальный массив `allTasks` и фильтр `activeFilter` позволяют фильтровать без лишних запросов к серверу.

5. **Безопасность и UX** — `escapeHtml()` защищает от XSS, переключение режимов карточки через CSS даёт плавный UX, валидация на обеих сторонах предотвращает ошибки, автоматические миграции упрощают развёртывание.
