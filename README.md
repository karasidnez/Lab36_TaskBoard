**Выполнил:** Тимонин И.В ИСП-233

## Инструкция по запуску

1. **Запуск бэкенда (ASP.NET Core API)**  
   - Откройте терминал в корне проекта.  
   - Перейдите в папку с проектом API: `cd MemesApi`  
   - Выполните команду: `dotnet run`  
   - Сервер запустится по адресу `http://localhost:5000`  

2. **Запуск фронтенда**  
   - Откройте файл `frontend/index.html` с помощью **Live Server** в VS Code.  
   - Страница будет доступна, например, на `http://localhost:5666`  

## Что изучили в работе

| Концепция | Где используется |
|-----------|------------------|
| `fetch(url)` | GET-запрос к API (получение списка мемов) |
| `fetch(url, { method, headers, body })` | POST и DELETE запросы (добавление и удаление мемов) |
| `response.ok` | Проверка успешности ответа сервера (статус 200–299) |
| `response.json()` | Чтение JSON из тела ответа (превращение в JS-объект) |
| `JSON.stringify(...)` | Превращение объекта JavaScript в JSON-строку для отправки на сервер |
| `async / await` | Ожидание ответа от сервера (асинхронные вызовы fetch) |
| `try / catch / finally` | Обработка ошибок при выполнении fetch (например, сетевые сбои) |
| CORS | Разрешение запросов между разными портами (браузер блокирует, если не настроить) |
| `AddCors` + `UseCors` | Включение CORS в ASP.NET Core — оба шага обязательны для работы фронтенда |
